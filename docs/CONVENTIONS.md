# Epoch 数据约定

状态：Phase 0 v1

## 时间

- 数据库存储时间统一使用 UTC `timestamptz`；页面默认使用 `Asia/Shanghai` 展示。
- 日频数据使用 ISO `YYYY-MM-DD`，日期代表对应市场交易日，不代表 UTC 自然日。
- 外部数据区分 `observed_at`、`effective_at`、`recorded_at`；计算使用 `as_of` 表示信息截止点。
- `.NDX` 使用 `America/New_York` 市场时区和显式交易日历。节假日表按年份版本化更新，不靠周末规则猜测。

## 货币

- 基础币种、报告币种与风险口径均为 USD。
- 每个金额必须携带原始币种；跨币种估值必须引用同日 FX 观察值或明确标记降级。
- Phase 0 支持 `USD`、`KRW`、`HKD`、`CNY`，新增币种必须先扩展 Schema 和测试。

## 证券标识

- 内部证券标识采用 `VENUE:LOCAL_ID`，例如 `XNAS:GOOGL`、`XKRX:000660`、`CASH:USD`。
- ticker 只用于展示，不作为跨市场唯一键。
- 发行人、证券和账户是不同对象；同一发行人的 ADR、本地股与 ETF 底层持仓不得合并成同一证券。

## 确定性与精度

- 账本金额以最小货币单位保存，USD 计算使用整数美分。
- 原始导入以来源标识与内容哈希幂等；派生快照可以重建。
- 相同事实、代码、策略与参数版本必须生成字节级一致的计算结果。
