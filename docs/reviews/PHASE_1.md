## 验收结论

Phase 1“可信账本与组合表现”已完成合格对账。系统可以在关闭模型和 Agent 的情况下，确定性导入、归一化、重放并估值组合历史，计算组合表现，并将差异定位到显式事件、估值来源基差或有原因分类的残差组件。

历史期权与富途 7313 子账户缺少可导出的逐日日终市值，因此 78 个估值日采用显式残差桥接。这些数据不会被标记为独立市场估值，是本阶段验收的持续限定条件。

### 事件与仓位

- 536 条账本事件均具有唯一标识并满足对应类型契约；
- 113 条报告持仓全部带有显式券商基础币种估值；
- 113/113 条报告持仓完成基础币种换汇复算；
- 相邻报告快照之间的 71/71 个有效市场证券数量比较一致；
- 8 笔跨时区边界交易已按交易生效日对齐；
- 4/4 个期末账户—币种现金端点闭合。

### 表现

- 545 个连续日频绩效点覆盖 `2025-01-20` 至 `2026-07-18`；
- 净值链最大链接误差为 `5.01e-9`；
- 全区间 TWR 为 `+49.16%`；
- XIRR 年化 MWR 为 `+29.94%`，全区间累计 MWR 为 `+47.75%`；
- 四个非零外部现金流日均保留显式 Modified Dietz 权重；
- 逐日资产收益最大复算误差为 `3.95e-5`，低于 `5e-5` 源数据精度容差。

### 行情、重放与估值

- 28/28 个规范化市场标的和 2/2 个汇率对具有日频行情覆盖，共 11,148 条观测；
- 545/545 天均完成状态重放和资产入账；
- 467 个独立估值日相对券商组合资产的最大来源基差为 `0.532%`，低于 `0.75%` 合格阈值；
- 78 个残差桥接日全部保留原因分类：19 天为 7313 子账户、58 天为历史期权、1 天为周末券商快照时点；
- 基线检查最终返回 `healthy: true` 和 `ledgerReconciled: true`。

## 完成标准

- 选定历史区间已与券商报表完成合格对账；
- 所有差异均可定位到事件、估值来源基差或显式残差组件；
- Flex 报表重复导入不会生成重复记录；
- 账本、估值和表现计算不依赖模型或 Agent；
- Web/API 在数据库不可用时会明确标记降级，不将合成数据或残差值伪装为真实市场输入。

## 限定条件

1. 78 个残差桥接日不属于独立行情估值，后续若获得历史期权或子账户日终市值，应替换残差并重新验收；
2. `0.75%` 是券商快照与独立重放之间的来源基差合格阈值，不代表交易或现金账本允许同等误差；
3. 三只货币基金按现金等价物处理，其申赎属于现金管理内部转换；管理人 NAV 只用于辅助核验；
4. 数据库迁移幂等和 Flex 重复导入由 PostgreSQL 集成测试验证，CI 中使用真实 PostgreSQL 服务执行。
