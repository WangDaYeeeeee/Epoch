- 主界面新增研究记忆搜索框，可直接查询统一记忆接口，明确显示只读边界、加载状态、空结果和错误状态；
- 未配置的日内、期权和微观结构数据源保持 fail-closed，不参与计算。

## 数据源评估

约束是 HTTPS 拉取、无需常驻券商会话、保留原始观测时间，并区分指示性与合并行情。

| 能力 | 候选 | 结论 |
| --- | --- | --- |
| 严格 RS± / ΔJ | Alpaca 1 分钟 bars | 接入最简单；免费层为 IEX，不能代表全市场成交量，适合作为低成本试验而非最终合并口径 |
| 严格 RS± / ΔJ | Massive aggregates | REST 可提供自定义分钟聚合；需要确认订阅档位和历史深度 |
| 严格 RS± / ΔJ | Databento historical | 支持历史日内 OHLCV，覆盖与可重放性较好；商业成本待确认 |
| IV / put skew | Cboe DataShop Option Sentiment | 直接提供 `iv30`、标准化 25Δ/30 日 skew 等日频特征，最接近所需口径；属于商业数据 |
| IV / Greeks | Massive / Alpaca options snapshots | HTTPS 快照可返回 IV/Greeks；历史链、OPRA 权限和缺失值规则必须按订阅验证 |
| 自行计算 IV/skew | Databento OPRA | 原始 OPRA 数据可重放，但需要自行完成曲面、期限和 delta 插值，工程与验证成本最高 |

首选验证路径：

1. 日内先用 Alpaca IEX 做非生产回放，确认 RS±/ΔJ 管道和增量价值；若通过回测，再比较 Massive/Databento 的合并覆盖与成本。
2. 期权优先索取 Cboe Option Sentiment 样本，验证 QQQ、SOXX 和可选标的覆盖；若采购不合适，再评估 OPRA 快照或自建曲面。
3. SKHY 不假定存在可用美股期权链；必须单独确认底层/对应市场覆盖。

## Alpaca 非生产回放入口

已实现分页的 Alpaca IEX `1Min` HTTPS 连接器。连接器保留 `US:<symbol>`、行情时间、抓取时间和 `alpaca-iex` 来源标记；导入幂等，成功后数据源会被标记为 `active/degraded`，明确表示 IEX 并非全市场合并口径。缺少凭证或请求失败时不会产生行情，也不会启用模型信号。

连接器导入完成后会立即刷新每日严格半方差特征。当前验收为 40 个测试文件、149 项测试全部通过，其中 23 项使用真实 PostgreSQL；生产构建和差异检查通过。

主界面已使用本机 3000 服务完成浏览器渲染验收：长期质量导航可达，10 条真实预测评估、数据源状态和零覆盖的未启用信号均按 fail-closed 状态正确呈现。

`GET /api/v1/research/memory?q=<query>&limit=<1-100>` 为只读接口；查询限制为 2–200 字符，最多使用 10 个去重词元。真实 PostgreSQL 集成测试验证同一查询可同时召回命题与证据，验收临时数据已清理；本机 3000 接口与 422 无效查询保护均已实测。

研究记忆搜索界面已在本机 3000 完成浏览器渲染验收，导航锚点、关键词输入、只读说明和响应式布局正常。

## 信息架构重组

原单页纵向平铺已拆分为四个一级入口，并使用可刷新、可收藏的独立 URL：

- `/` 工作台：Operations、事件视界、组合风险、漂移和调仓测算；
- `/portfolio` 组合：组合指标、绩效曲线、持仓、敞口穿透和收益归因；
- `/research` 研究：事件/主题/复盘录入、决策日志和研究记忆；
- `/system` 系统：预测与数据源质量、数据健康、行情刷新和账本对账。

四页共享同一数据库读取和领域组件，不复制计算逻辑。浏览器验收逐页确认一级标题、当前导航高亮、所属板块存在、跨页板块不渲染；组合指标栅格、研究表单和系统质量表均完成视觉复验。
